# SENTINEL

Wearable fall detection device on ESP32, for lone worker protection.

## Status

- [x] Heartbeat LED and serial boot message
- [ ] Motion sensor (MPU6050)
- [ ] Fall detection

## Hardware

- ESP32 devkit
- MPU6050 (GY-521)

## Build and flash

Open the project in VS Code with PlatformIO, then click Build and Upload.
